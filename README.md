# 大肥鱼知识管家

遇到公开知识缺口时搜索并阅读正文，核对后保存带来源的摘要，后续聊天按话题检索。群友私事继续由已有记忆插件处理。
功能：

- 读取真实网页正文，保存前校验引文确实来自本轮读取的内容。
- 两个不同域名的证据，或配置认可的一手来源，才允许入库。该门槛不等于自动保证事实正确，仍需模型对照证据理解。
- 保存来源、原文证据、核对时间和适用版本；新闻价格1天、版本资料30天、稳定资料90天。
- 同主题同版本去重更新，并保留旧记录修订历史。过期知识保留在库中，但不自动注入当前回答。
- 关键词与现有本地bge-m3检索结合，嵌入服务不可用时使用关键词。
- 按用户隔离交流偏好，只接受当前消息中有原话依据的反馈；常见的“别反问、别复述、别汇报记忆、短点”等纠正可直接捕获。
- 不需要额外启动一个整理模型；主聊天模型利用来源凭证决定哪些知识值得保存。

默认限制：每日20次搜索、40次正文读取，每次最多2篇正文。按接口当前单价计算，本插件搜索和正文接口最多约0.30元/日，另有主聊天模型阅读与回答的Token费用。此限制不覆盖原有其他联网工具和插件。

在AstrBot插件配置中调整开关、预算、一手来源域名和本地嵌入提供商。聊天发送 `/鱼知识` 可以查看有效资料数量、过期数量和今日使用量。

数据保存在AstrBot的本插件数据目录中的 `knowledge.sqlite3`。此插件不修改原有的人格卡、长期记忆、成长进度或自我进化审核设置。

学习工具：`fish_knowledge_search`、`fish_knowledge_save`、`fish_knowledge_find`。交流习惯工具：`fish_style_feedback`。

模块只读取公开HTTP/HTTPS页面，不执行网页中的指令。搜索词限制个人账号、联系方式与聊天标记；私人经历不应发送到公开搜索。调用日志不输出密钥和完整私人反馈。

每轮召回的资料和交流偏好通过 `req.extra_user_content_parts` 追加到当前用户消息，并标为临时内容。插件不改写系统提示词或前面的会话历史；临时块仅供本轮模型使用，不持久化到会话历史。兼容SDK中的 `make_as_temp()` 和 `mark_as_temp()` 命名。
